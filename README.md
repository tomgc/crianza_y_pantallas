# Crianza y Pantallas

Matriz interactiva de evidencia científica sobre el efecto de las pantallas en el desarrollo infantil (0–12 años), organizada por dominio del desarrollo y tramo etario.

**Sitio publicado:** https://tomgc.github.io/crianza_y_pantallas/

## Contenido

- **Matriz 10 × 5** — 10 dominios del desarrollo × 5 tramos etarios (50 celdas navegables).
- **Bibliografía** — 65 entradas con popovers navegables (formato `[ref]`).
- **Andamiaje** — cascadas de evidencia entre celdas relacionadas.
- **Glosario** — 22 términos clave del desarrollo infantil.

## Estructura del repositorio

- `index.html` — sitio publicado por GitHub Pages. Generado por `00_build.sh`; no se edita a mano.
- `10_fuentes/` — fuentes del sitio: template, estilos, JS y datos JSON.
- `20_recursos/` — instrucciones para descarga local de documentos UNICEF y CJE UC.
- `30_documentacion/` — documentación del proyecto, traspasos de sesión y andamios históricos.

## Fuentes principales

- Meta-análisis y revisiones sistemáticas peer-reviewed (2020–2026).
- Documentos UNICEF Chile y UNICEF LAC sobre crianza en la era digital.
- Centro de Justicia Educacional UC (CJE UC) — informes sobre pantallas en primera infancia.

## Uso local

```bash
git clone https://github.com/tomgc/crianza_y_pantallas.git
open index.html
```

No requiere servidor ni dependencias externas.
