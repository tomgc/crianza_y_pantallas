# Crianza y Pantallas

Matriz interactiva de evidencia científica sobre el efecto de las pantallas en la infancia (0–18 años), con foco en desarrollo cognitivo, lenguaje, motor, socioemocional, sueño, salud física y atención.

**Sitio publicado:** https://tomgc.github.io/crianza_y_pantallas/

## Contenido

- `index.html` — Matriz única autocontenida (HTML + CSS + JS inline, sin dependencias externas). Incluye:
  - Tabla cruzada **dominios × edades** con celdas navegables.
  - **Andamiaje** de cascadas de evidencia (regulación emocional, socioemocional → salud mental, etc.).
  - **Bibliografía** con 52 entradas y 39 citas navegables (formato `[ref]`).
- `recursos/` — Instrucciones para descarga local de documentos UNICEF y CJE UC.
- `50_documentacion/traspasos/` — Histórico de sesiones de desarrollo.

## Fuentes principales

- Meta-análisis y revisiones sistemáticas peer-reviewed (2018–2025).
- Documentos UNICEF Chile y UNICEF LAC sobre crianza en la era digital.
- Centro de Justicia Educacional UC (CJE UC) — informes sobre pantallas en primera infancia y Ola 4 Mil Primeros Días.

## Uso local

Abrir `index.html` directamente en cualquier navegador moderno. No requiere servidor.
