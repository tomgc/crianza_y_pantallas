# 20_recursos/papers/

PDFs de papers referenciados en la matriz de Crianza y Pantallas.

## Convención de nombrado

`{ID_bibliografia}.pdf`

El ID es exactamente el que aparece en `10_fuentes/data/bibliografia.json`. Ejemplos:

- `Maertens2021.pdf`
- `Essex2025.pdf`
- `Baumgartner2014.pdf`

**Paper aún sin ID en el corpus:** nombrar como `{AutorAño}_pendiente.pdf` y renombrar al ID definitivo al integrarlo.

## Scope

Solo papers usados en alguna celda de la matriz (referenciados en `claims.json` o `glosario-data.js`). No papers de referencia general.

## Acceso

Los PDFs están versionados en Git junto con el proyecto. Solo incluir papers de acceso abierto (PMC, preprints, repositorios institucionales) o con licencia compatible.
